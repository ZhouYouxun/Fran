# 雷神之锤：头顶蓄力与放射雷击

## 本地参考

查看了相邻 CalamityMod 的 `StellarContempt`、`StellarContemptHammer`、`StellarContemptEcho` 和 `StellarContemptBlast`。

- 普通锤命中的月耀确实使用原版 `ProjectileID.LunarFlare`。
- 重击的主要视觉在 `StellarContemptEcho.PreKill`：156 个交替亮星/光尘、40 个顺着入射方向的高速光尘、短促光芒、两个不同压扁比例的冲击环、撞击音和震屏。
- 本次借鉴重击的粒子分层和方向感，使用 Fran 自己的蓝色粒子；没有添加月耀伤害或灾厄依赖。

## 结果

- 法阵生成在施法者头顶，横向随机偏移 −150～150 像素，向上偏移 170～260 像素，生成后固定于该世界位置。
- 保留原法阵的旋转与收束效果；从法阵出现起绘制透明锤体，逐渐显形并加速旋转。
- 保留原来的释放判断 `timeLeft == 25`，即原 75 帧计时经过 50 帧时出锤。
- 出锤瞬间选择鼠标最近的可攻击 Boss；没有可攻击 Boss 时选择鼠标最近的可攻击普通敌人。包括可攻击的多节 Boss 部位，排除无敌和不可追踪单位。
- 飞出后保持目标，失效才重选；视野内没有有效敌人时，锤子飞向出锤瞬间的鼠标位置并引爆；飞行中鼠标移动或新出现的敌人不会改变这个备用落点。伙伴通过其原有上下文使用自身瞄准位置。
- 锤子从法阵中心出发，保留飞行速度、转向、碰撞、锤体伤害和爆炸伤害参数。
- 移除旧的天降雷束和五束天降粗雷；命中时向外释放七道蓝色粗雷，混合细电弧。
- 粒子使用交替亮星/光尘、高速定向碎光、短闪和双层扁长冲击环。保留音效与震屏参数。
- 保存入射方向，避免锤子贴到目标中心后速度清零使视觉错误朝下。

## 验证

- 编译：0 警告、0 错误。
- 隔离 tModLoader 服务端：`HAMMER_RUNTIME_PASS: 196 checks`。
- 覆盖鼠标距离与玩家距离区分、Boss 优先、无敌过滤、多节 Boss、50 帧等待、固定法阵、释放时重选、保持锁定、无目标、旁观端不重复释放、计时序列化、实际锤体命中、爆炸倍率/范围、七道向外蓝雷及无伤害属性。
- 测试入口是 `Tests/Runtime/HammerSmokeTest.cs`，需构建参数 `FranHammerTests=true` 和运行参数 `-franhammertest`。普通构建不包含该测试。
- 服务端测试不验证画面、帧率、声音或真实双客户端联机；这些仍待游戏内确认。
