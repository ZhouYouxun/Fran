# 弗兰玩家角色贴图制作教程

> 给画师与接入程序员看的交付说明。
> 适用：Terraria 1.4 系列的 tModLoader 玩家外观/装备贴图格式。
> 模板来源：tModLoader 官方 Wiki 与官方 ExampleMod 1.4.5 分支。
> 模板下载并核对日期：2026-09-05。

---

## 一、只看这一页也能开工

弗兰不是 NPC，也不是一张从上到下循环播放的“整个人动画”。她仍然是 Terraria 玩家，走路、跳跃、使用物品和受击等状态都由游戏控制；我们只是把玩家正在显示的头部、身体和腿部装备槽替换成弗兰的贴图。

画师最终必须交付下面三张 PNG：


| 最终文件        |     固定尺寸 | 内容                          |
| --------------- | -----------: | ----------------------------- |
| `Fran_Head.png` | **40×1120** | 头部，纵向 20 格，每格 40×56 |
| `Fran_Body.png` | **360×224** | 身体和手臂的 1.4 复合布局     |
| `Fran_Legs.png` | **40×1120** | 腿部，纵向 20 格，每格 40×56 |

请直接打开这个文件夹里的三张图改画：

- [`01_Fran_Head_头部模板.png`](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/01_Fran_Head_头部模板.png)
- [`02_Fran_Body_身体模板.png`](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/02_Fran_Body_身体模板.png)
- [`03_Fran_Legs_腿部模板.png`](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/03_Fran_Legs_腿部模板.png)

最重要的四条规则：

1. **不要改变画布尺寸。**
2. **不要移动、裁剪、合并或重新排列模板中的格子。**
3. **不要把三张图做成普通 GIF 式连续动画。**
4. **导出透明背景的 RGBA PNG，不要留下白底或黑底。**

程序员不需要规定“每隔几帧切下一张”。Terraria 会根据玩家当前状态自动选择头、身体、手臂和腿部区域。

## 二、当前 Fran 模组实际上是怎么显示人物的

### 2.1 目前还没有正式的弗兰人物贴图

当前模组进入 `FranMode` 后，暂时强制显示的是原版外观：

- 原版猫耳；
- 原版便装上衣；
- 原版便装裤子；
- 再由代码改变头发、眼睛、皮肤和衣服颜色。

也就是说，当前看起来像“套上了一套盔甲”，是因为程序借用了 Terraria 的 `Head / Body / Legs` 三个装备显示槽。它只是临时占位，并不是已经完成的弗兰美术。

当前进入弗兰模式的条件是：背包里有“师父”大剑。无需指定角色名字、佩戴装备或收藏物品。

这套模式属于“玩家人物换装/替皮”逻辑，不是城镇 NPC 逻辑。

### 2.2 “师父”是另一张独立的武器图

`Textures/师父本体.png` 当前是 **134×140 的单帧图片**。挥剑时程序整张读取，通过旋转、翻转、移动和缩放形成动作，没有从图中切换序列帧。

所以要分清：


| 内容               | 现在怎么动                    | 是否由画师安排播放速度 |
| ------------------ | ----------------------------- | ---------------------- |
| 弗兰玩家人物       | Terraria 自动选择玩家动作区域 | 否                     |
| 师父武器           | 程序旋转和移动一张单帧图片    | 否                     |
| 将来的多帧武器特效 | 程序裁切图集并计时换帧        | 是，需和程序员约定     |

另外，现有源码中的“师父”物品没有检查 `FranMode`，并且还保留了合成配方。因此“只有解锁弗兰才能使用师父”目前是设计目标，不是已经由源码严格执行的限制。

## 三、为什么人物贴图不能按普通多帧动画画

普通序列帧通常是：

```text
第0帧 -> 等5 tick -> 第1帧 -> 等5 tick -> 第2帧 -> 循环
```

Terraria 玩家不是这样工作的。游戏会分别计算：

- `bodyFrame`：身体和手臂现在应该使用什么姿势；
- `legFrame`：腿部现在应该使用什么姿势；
- `headFrame`：头部应如何跟随当前动作；
- 玩家朝向、重力方向、身体旋转、手臂旋转、台阶高度偏移等。

因此玩家可以一边走路，一边挥动手臂使用物品：腿部继续读取走路姿势，身体和手臂则读取使用物品姿势。

如果把弗兰做成“一格就是一整个完整人物”的普通动画，就很难同时组合这些动作，常见结果是：

- 走路时使用武器，腿突然停止；
- 人物看起来在地面滑行；
- 手臂和武器对不上；
- 跳跃、重力倒置或骑乘时错位。

所以本项目采用官方的玩家装备贴图结构，让 Terraria 帮我们完成动作组合。

## 四、三张核心贴图分别怎么画

### 4.1 `Fran_Head.png`：头部

![头部模板](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/01_Fran_Head_头部模板.png)

- 固定尺寸：**40×1120**。
- 一共 20 个纵向区域。
- 每个区域：**40×56**。
- 每一格的头部都必须保持在模板对应位置。
- 不要把 20 格理解成从上往下连续播放的 20 帧；游戏会按状态选择对应区域。

官方还提供了一张 1× 像素比例的头部定位参考：

![官方头部定位参考](./弗兰角色贴图模板/02_官方结构参考/08_Head_头部参考.png)

注意：这张官方定位参考是 **20×560**，只是便于看像素位置的 1× 参考；本项目真正交付和导入的是上面的 **40×1120** 文件。

#### 弗兰头部建议

- 猫耳、短发主体和脸部遮挡可以先画进 Head。
- 如果后发很长、会垂到身体后面，不要全部硬塞进 Head；应额外交付后发层。
- 如果刘海必须覆盖盔甲、手臂或部分武器，可额外交付前景层。

可选附加文件：


| 可选文件             | 用途                           |
| -------------------- | ------------------------------ |
| `Fran_BackHair.png`  | 画在身体后面的长发、发尾       |
| `Fran_FrontHair.png` | 画在脸或身体前面的刘海、发丝   |
| `Fran_Head_Glow.png` | 发光眼睛、魔力纹路等独立发光层 |

附加层没有固定官方尺寸，必须在正式接入前与程序员确认；如果当前只做基础角色，可以暂时不做。

### 4.2 `Fran_Body.png`：身体和手臂

![身体模板](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/02_Fran_Body_身体模板.png)

- 固定尺寸：**360×224**。
- 可以按 40×56 看成 9 列 × 4 行的定位网格。
- 但它**不是普通的 36 帧动画**。
- 其中包含身体、前后手臂和特殊使用物品姿势需要的“扩展手臂”区域。

tModLoader 1.4 的 Body 已把旧格式中的 `Body`、`Arms`、`FemaleBody` 合并成一张复合贴图。请不要按照旧教程再单独提交三张旧格式文件。

画 Body 时优先打开这张官方标注图放在旁边：

![身体区域标注](./弗兰角色贴图模板/02_官方结构参考/07_Body_ColoredAreas_Labeled_标注.png)

另外几张参考图用于理解实际组合效果：

![完整玩家参考](./弗兰角色贴图模板/02_官方结构参考/02_Body_FullPlayer_完整玩家.png)

![铜甲参考](./弗兰角色贴图模板/02_官方结构参考/03_Body_CopperArmor_铜甲.png)

![稻草人上衣参考](./弗兰角色贴图模板/02_官方结构参考/04_Body_ScarecrowShirt_稻草人.png)

#### Body 作画要点

- 身体宽度、肩膀位置和手腕位置必须服从模板锚点。
- 衣袖需要跟随每个手臂区域分别绘制，不能只画一套正面立绘。
- 手掌如果要保留原版肤色，可以只画衣袖；如果要完全替换角色皮肤，需要把应该遮住的区域完整画好。
- 宽袖、披风、围巾等超出模板很多的部件最好拆成自定义前后层，否则很容易在挥动手臂时穿帮。
- 不要通过把整个图放大来让角色显得更高；玩家碰撞箱和手持物锚点不会跟着改变。

### 4.3 `Fran_Legs.png`：腿部

![腿部模板](./弗兰角色贴图模板/01_可直接改画_ExampleCostume/03_Fran_Legs_腿部模板.png)

- 固定尺寸：**40×1120**。
- 一共 20 个纵向区域。
- 每个区域：**40×56**。
- 站立、走路、跳跃、下落等状态由游戏选择，不由画师安排播放间隔。

官方 1× 腿部定位参考：

![官方腿部定位参考](./弗兰角色贴图模板/02_官方结构参考/09_Legs_腿部参考.png)

这张参考是 **20×560**；正式交付仍使用 **40×1120**。

#### Legs 作画要点

- 鞋底落点和腿部中心不能随意漂移。
- 裙摆如果覆盖双腿，20 个区域都要检查走路时是否断裂。
- 长裙或大衣下摆可能需要由 Body 的长外套层或额外自定义层处理，不能简单把所有内容塞进 Legs。

## 五、推荐的实际作画流程

### 第一步：建立工作文件

把下面三张模板复制到画师自己的工作目录：

```text
01_Fran_Head_头部模板.png
02_Fran_Body_身体模板.png
03_Fran_Legs_腿部模板.png
```

建议使用 Aseprite、Photoshop、Krita 或其他支持透明 PNG 和像素级编辑的软件。

### 第二步：保持像素设置

- 关闭平滑缩放、抗锯齿和自动模糊。
- 缩放预览时使用最近邻算法。
- 如果软件支持像素网格，可给 Head/Legs 设置 40×56 的参考网格。
- Body 可设置 40×56 网格辅助定位，但不要把每格误当成完整动画帧。

### 第三步：先完成静态辨识度

先确定：

- 黑发和猫耳的轮廓；
- 服装主色和明暗层次；
- 鞋子、袖口、领口等容易辨认的部位；
- 角色在游戏默认缩放下是否仍能看出是弗兰。

不要一开始就投入大量时间画发光或粒子。人物本体在不发光状态下也必须清楚。

### 第四步：按参考逐区域补齐

推荐顺序：

1. 先画 Head 的第一格和 Body 的默认站立区域；
2. 完成 Legs 的站立与基础行走区域；
3. 补齐 Body 的所有手臂和特殊姿势区域；
4. 补齐 Head、Legs 的全部 20 格；
5. 最后再做后发、前发、发光等可选层。

### 第五步：导出

导出前确认：

- PNG；
- RGBA；
- 透明背景；
- 原始尺寸；
- 不做有损压缩；
- 不缩放；
- 不裁掉透明边缘；
- 文件名清晰且没有“最终版2真的最终版”一类混乱后缀。

最终推荐文件名：

```text
Fran_Head.png
Fran_Body.png
Fran_Legs.png
```

## 七、程序接入方式概览

画师不需要编写这部分。这里用于让程序员知道三张图如何进入 Fran。

接入思路与官方 `ExampleCostume` 相同：

1. 用 `EquipLoader.AddEquipTexture` 注册 Head、Body、Legs 三个装备贴图；
2. 在 `FrameEffects()` 中，仅当 `FranMode` 生效时切换玩家的 `head/body/legs` 显示槽；
3. 设置隐藏原版皮肤和手臂的标志；
4. 由 Terraria 原生玩家绘制系统使用 `bodyFrame` 和 `legFrame` 自动裁切；
5. 长发、特殊前景或发光部分再使用 `PlayerDrawLayer` 添加。

简化示意：

```csharp
// 加载时注册三张装备贴图。
EquipLoader.AddEquipTexture(Mod, ".../Fran_Head", EquipType.Head, ...);
EquipLoader.AddEquipTexture(Mod, ".../Fran_Body", EquipType.Body, ...);
EquipLoader.AddEquipTexture(Mod, ".../Fran_Legs", EquipType.Legs, ...);

// 每帧只负责决定是否显示弗兰装备槽，不负责手动播放人物动画。
public override void FrameEffects()
{
    if (!FranMode)
        return;

    Player.head = franHeadSlot;
    Player.body = franBodySlot;
    Player.legs = franLegsSlot;
}
```

还需要按实际美术设置类似下面的隐藏规则：

```csharp
ArmorIDs.Head.Sets.DrawHead[franHeadSlot] = false;
ArmorIDs.Body.Sets.HidesTopSkin[franBodySlot] = true;
ArmorIDs.Body.Sets.HidesArms[franBodySlot] = true;
ArmorIDs.Legs.Sets.HidesBottomSkin[franLegsSlot] = true;
```

官方完整示例已经下载到：

- [`ExampleCostume.cs`](./弗兰角色贴图模板/03_官方代码示例/ExampleCostume.cs)

注意：上面的代码只是结构示意。最终接入时必须使用 Fran 模组自己的路径、槽位字段和联机显示逻辑，不能直接原样粘贴类名。

## 八、什么时候才需要自己写“每几帧换一帧”

只有下面这些情况通常需要手动计时：

- 自定义弹幕序列帧；
- 自定义武器本体图集；
- 单独的魔法阵、火焰、爆炸等特效；
- 完全脱离原版玩家骨架的整人动画。

例如一张纵向 6 帧的弹幕图，程序可能会设置 6 帧，并每隔若干 tick 增加一次当前帧编号。但玩家 Head/Body/Legs 模板不应该采用这套逻辑。

如果以后要把“师父”做成多帧武器图，必须提前和程序员约定：

- 横排还是竖排；
- 每帧宽高；
- 总帧数；
- 每帧持续时间；
- 哪些攻击阶段对应哪些帧；
- 发光层是否使用相同布局。

这些约定只针对师父武器，不影响弗兰玩家人物模板。

## 十一、最终交付给程序员的压缩包应包含什么

```text
Fran角色贴图_交付日期.zip
├─ Fran_Head.png
├─ Fran_Body.png
├─ Fran_Legs.png
├─ Fran_BackHair.png          可选
├─ Fran_FrontHair.png         可选
├─ Fran_Head_Glow.png         可选
├─ 弗兰角色源文件.aseprite     或 PSD/KRA
└─ 说明.txt                   写明可选层的前后顺序和特殊要求
```

只要三张核心 PNG 尺寸正确、位置不变、透明背景正确，程序就可以先完成基础人物接入；长发、发光、特殊动作和披风可以在基础版本通过后再逐项增加。
