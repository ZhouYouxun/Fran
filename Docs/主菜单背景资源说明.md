# Fran主菜单背景资产说明

- 运行时资产：`FranMenuBackground.png`
- 当前尺寸：1672×941，24位RGB，约16:9
- 官方源图：`https://tenken-anime.com/assets/top/vis-h1.webp`
- 官方页面：`https://tenken-anime.com/`
- 处理方式：身份保持型横向扩图；无文字、无Logo、无日期、无水印；左侧为菜单按钮保留暗色空间。
- 使用代码：`Content/MainMenu/FranMainMenu.cs`
- 配置开关：`FranClientConfig.EnableCustomMainMenu`，默认开启。

替换图片时保持文件名和资源路径不变。画师正式图建议3840×2160，角色和师父放在中央70%安全区。
