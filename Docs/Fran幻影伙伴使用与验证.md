# Fran 幻影伙伴第一版

## 使用

物品：**弗兰的约定**（内部名称 `FranCompanionStaff`）。工作台合成：坠落之星 ×3、丝绸 ×5、铁锭或铅锭 ×5。物品图标暂用原版矮人法杖。

- 左键使用召唤；再次使用召回现有 Fran，保留她的指令。
- 距离 Fran 200 像素内右键角色，打开独立战术菜单；选择“自动适应”或一个已解锁战术。
- 右键使用召唤物品、菜单“取消召唤”可收回；主人死亡或离线也会收回。
- 一人一名，不占召唤栏。重新召唤恢复自动模式，手动设置不跨存档保存。
- 师父固定持有，无装备管理、拾取、消耗品或背包；无敌，无接触伤害，飞行不耗尽。

## 战斗

世界进度决定可用战术和师父基础伤害，召唤者的召唤伤害加成作用于伙伴。每次选定一种战术占满当前可用槽，因此采用既有全选效果：持续居合刀盘、一轮四刀落锤等。钛金套只有外观，没有钛金碎片或防具属性。

自动模式每 30 帧评估，通常保持至少 180 帧，新选择须超过当前评分 18 分；重伤治疗可提前排队，但仍等当前动作收尾。切换会排队到连段边界，持续刀盘先自然减速再换。虫体多个节段按一名敌人计数。魔力屏障从自动候选池完全排除，仅手动解锁后可选。

跟随以飞行追击为主，障碍碰撞后尝试继续移动，持续卡住 90 帧或距离超过 1200 像素时搜寻主人附近安全位置传送。不实现 MoreAIPlayer 的完整地面寻路、挖掘或开门。

## 实现位置

`Content/Companions` 集中存放召唤实体、战术决策、网络命令、弹幕归属与执行上下文、外观和 UI。师父伤害与技能效果仍复用主模组现有实现。参考源码来自 `ModSources/MoreAIPlayer`，无运行时依赖。

## 验证与边界

- 策略测试：`dotnet run --project Tests/Companion/Companion.Tests.csproj`，131087 项断言，包括所有解锁掩码与历史战术值的屏障排除检查。
- 独立 tModLoader 无图形服务器：实际运行八种战术，检查附加弹幕产生、目标扣血、蓝辉治疗、越权指令拒绝、远距回归、取消后的子弹幕清理，以及每步保留槽/真实玩家引用恢复。测试在临时新建世界中运行。
- 运行测试源码只在显式 `-p:FranCompanionTests=true` 构建时纳入；还须启动参数 `-francompaniontest` 才会执行。正常发布包不包含测试类，游戏内源代码构建也通过 buildIgnore 排除 Tests。
- 已通过编译与独立打包；尚未完成图形客户端中的外观/交互验收，也未以两个真实客户端确认网络表现。

首次游戏内验收：召出 Fran，确认钛金三件套和翅膀、连续挥剑、移动跟随、右键菜单；切换居合再切其他战术；将战术改为屏障后再回自动；远距传送；主人死亡清理。多人另验晚加入、两名 Fran 同场、互不控制、伤害不重复和治疗归属。
