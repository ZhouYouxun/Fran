# 三模组差异与 Fran 吸收方案

## 1. 一句话判断

- Calamity 教 Fran “武器到底怎么动”。
- Redemption 教 Fran “接触目标或地面的一瞬间怎么有重量”。
- Homeward Journey 教 Fran “怎样用一套规则覆盖一把武器的长期成长，而不是不断换系统”。

三者必须分工吸收。让其中任何一个模组独占 Fran 的动作、特效和成长设计，都会带入它自身最明显的缺点。

## 2. Calamity 与 Redemption 到底有什么区别

### 2.1 动作抽象

Calamity 的 `BaseSwordHoldoutProjectile` 先定义启动、有效挥击、收招，再允许武器覆写曲线、距离和尾迹。它首先保证“动作是连续的”。

Redemption 的 `TrueMeleeProjectile` 只提供攻速和真近战基本字段；很多剑在自己的 AI 中直接计算位置和旋转。它首先保证“这把武器有自己的演出”。

结论：Fran 的左键骨架应像 Calamity，单段演出事件可以像 Redemption。

### 2.2 刀光生成

Calamity 高阶武器通常先生成一串连续轨迹点，再让宽度函数、颜色函数和 Shader 给轨迹上材质。刀光能自然服从曲线。

Redemption 很多武器使用与动作帧同步的效果贴图；少数枪/飞行武器才接 Primitive Trail。它更擅长“这一帧发生什么”。

结论：Fran 的持续刀路用连续几何；接触爆点、重击震波、屏障破裂等短事件用逐帧贴图。

### 2.3 打击重量

Calamity 常靠速度曲线、武器形变、亮芯、次级弹幕和短暂停顿制造重量。

Redemption 的 Gravity Hammer、Hammer of Proving 会先确定接触帧和接触地点，再播放声音、震屏、粒子与沿地形冲击。

结论：Fran 的强化斩应使用 Calamity 式中段加速，再用 Redemption 式接触帧完成落点反馈。

### 2.4 玩家/敌人推动

两者都有不能照搬的部分：Earth 会推敌人；Exoblade 特殊攻击会重写玩家速度；Redemption 的锤和 Ukonvasara 会推动、旋转或控制玩家。

结论：这些都是“技能状态”，不是“挥舞手感”。Fran 左键四段完全禁止写入玩家速度和敌人位置/速度。

## 3. Homeward Journey 在二者之外提供了什么

旅人的 `GiantSlash` 不追求每把剑都有一套复杂动作，而是用腰带给大量剑增加同一套蓄力挥砍。它解决的是系统覆盖问题：如何让已有武器效果、原版剑和模组剑都能进入同一套成长规则。

Fran 不需要任意剑兼容，但需要打通全流程。因此应把这个思想改造成：

- 同一个攻击控制器从开局存在到终局。
- 阶段解锁只增加轨迹配置、技能入口和事件强度。
- 低阶内容不会因为新阶段到来而被废弃；可以被连段、资源或战术系统继续调用。
- 所有升级仍服从师傅与 Fran 的主题，而不是换成无关的能量炮。

## 4. Fran 左键四段的研究后定案

### 第一段：批砍

动作来源：Earth 的常规斩击节奏 + Calamity 标准三相位。

- 起手角明确，朝鼠标方向锁定。
- 中等宽度弧线，约 150°–190°，不必追求满屏。
- 使用平滑起步、中段加速、末端快速收束。
- 刀身线段是主要碰撞；刀光只复述刀身路径。
- 命中只有窄亮芯、少量暗色碎屑和轻微接触光，不产生飞行弹幕。

### 第二段：转圈

动作来源：Earth 的大角度动作概念，但改成 Fran 独立连续圆周。

- 角度约 300°–380°，让动作读作真正的环身回旋。
- 玩家速度完全保持原样；飞行中的纵向动量不受影响。
- 刀光从窄到宽再收窄，尾部延迟消散。
- 只在前半至中段拥有一次有效命中窗口，避免同一圈反复多段伤害破坏节奏。
- 圆周外不生成向四面八方飞散的无语义刀波。

### 第三段：强化批砍

动作来源：Exoblade 普通强化斩，不取 BonkDash。

- 与第一段共享起止方向语义，让玩家一眼看出是“第一段的强化版”。
- 启动更短，中段速度曲线更陡，收招略长以表现重量。
- 武器本体可做轻度压缩/拉伸，不能只把刀光放大。
- 刀光更窄、更锐、更亮，接触点使用 Redemption 式单帧爆点和短余波。
- 不发射光束，不推动玩家，不推动敌人。

### 第四段：突刺

动作来源：Gilded Proboscis 的轴向 Offset 和线段碰撞。

- 启动时师傅略微收回。
- 刀尖沿锁定方向快速前伸，主体不画大圆弧。
- 从手部到刀尖使用线段碰撞；长度随前伸距离实时变化。
- 残影是沿轴线排列的短影，不是扇形斩痕。
- 接触时出现小而极亮的尖端 flare，随后沿反方向快速消散。
- 玩家保持原速度；这是一记武器突刺，不是角色突进。

## 5. 左键统一参数模型

四段攻击应共享以下数据，而不是分别硬编码完整 AI：

| 参数 | 含义 |
|---|---|
| Startup / Active / Recovery | 启动、有效、收招时间 |
| StartAngle / EndAngle | 弧形攻击起止角；突刺可固定为同一轴线 |
| StartOffset / EndOffset | 武器离玩家的距离；突刺主要改变此项 |
| Easing | 角度或距离随时间的变化函数 |
| HitStart / HitEnd | 伤害窗口 |
| TrailWidth / TrailLifetime | 刀路宽度和独立消散时间 |
| ContactProfile | 轻斩、回旋、重斩、突刺四种接触事件 |
| MovementPolicy | 左键永远为 PreserveVelocity |

`MovementPolicy` 应作为显式规则存在，避免未来在单段 AI 中又偷偷写入 `player.velocity`。

## 6. 特效生产规则

### 6.1 每个效果必须回答四个问题

1. 它从哪里产生：刀背、刀刃、刀尖、命中点还是地面接触点？
2. 它沿什么方向运动：刀路切线、刀身法线、攻击轴线还是地形表面？
3. 它在动作哪一帧出现：预兆、挥动、接触还是余波？
4. 它向玩家表达什么：范围、危险、强化、格挡、治疗或资源状态？

回答不了其中任何一个，就属于“不明所以的弹幕”，应该删去或重做。

### 6.2 四层结构

| 层 | 时机 | 作用 | 建议技术 |
|---|---|---|---|
| 预兆层 | Startup | 告诉玩家方向和招式强度 | 武器轮廓、短流光、音调上升 |
| 刀路层 | Active | 展示真实运动范围 | 连续轨迹几何、Additive 材质 |
| 接触层 | 首次命中/接地 | 提供打击重量 | 逐帧爆点、短震屏、声音、火花 |
| 余波层 | Recovery 后半 | 让能量离场 | 无伤害轨迹消散、少量碎屑 |

### 6.3 暗色系不是把画面涂黑

Fran/师傅适合暗色外层，但需要可读的亮芯：

- 外层：低饱和黑紫、暗蓝、烟灰。
- 中层：较窄的主题色。
- 核心：短时白色或浅冷色，只在刃口和接触帧出现。
- 黑影不能遮住敌人轮廓和玩家自身位置。

## 7. 右键九技能重做时怎样使用这些研究

本报告不在证据不足时强行定九个技能名称，但可以先定生产约束：

- 攻击技能：优先改变武器轨迹、命中事件或战斗位置关系，不以“再发一圈弹幕”作为默认答案。
- 屏障技能：参考 Redemption 的独立 Shield/RenderTarget 分层思想，屏障应有承伤方向、剩余强度和破裂事件。
- 治疗技能：视觉从 Fran/师傅或命中资源回流到玩家，不能凭空落下绿色光雨；治疗量、频率和触发条件要可读。
- 冲刺技能：独立于左键，保留玩家纵向动量，只给水平方向速度；撞击敌人后产生黑色爆点。被其他冲刺装备覆盖时必须完全让位。
- 终局技能：可以采用多形态状态机，但每一形态仍要有唯一战术职责。

九技能正式安放时，每个阶段至少要回答：它解决哪一种 Terraria 流程威胁、为什么与该故事阶段关联、是否与已有技能重复。

## 8. 技术采用矩阵

| 概念 | 来源 | 采用程度 | Fran 用途 |
|---|---|---|---|
| Startup/Active/Recovery | Calamity | 完整采用思想 | 所有左键段和主动技能 |
| 可覆写缓动曲线 | Calamity | 完整采用思想 | 四段轨迹差异 |
| 刀身线段碰撞 | Calamity/HJ | 完整采用 | 弧斩与突刺 |
| Primitive Trail + 独立消散 | Calamity/Redemption | 采用原创实现 | 刀路主体 |
| 接触关键帧 | Redemption | 完整采用思想 | 强化斩、重击技能 |
| 逐帧效果贴图 | Redemption/HJ | 选择采用 | 接触爆点、屏障破裂 |
| 沿真实地形传播 | Redemption | 选择采用 | 未来地面技能，不用于所有斩击 |
| 全局成长覆盖 | HJ | 抽象采用 | 一把传奇武器打通流程 |
| 自动兼容任意剑 | HJ | 不采用 | Fran 没有此需求 |
| 敌人强制位移 | Earth | 禁止 | 左键绝不使用 |
| 玩家速度重写 | Exoblade/HJ Rapier/Redemption Hammer | 左键禁止 | 仅独立冲刺/身体技可用 |
| 复制原模组素材/代码 | 三者 | 禁止 | 只学习技术与动作语言 |

## 9. 重做顺序

1. 先完成无特效的四段武器轨迹、手臂姿势和碰撞。
2. 实机确认四段在地面、飞行、反向瞄准和高攻速下都不改玩家动量。
3. 给四段各加一条最小可读刀路。
4. 加接触层，不添加自由飞行弹幕。
5. 最后加声音、震屏、武器形变和余波。
6. 左键稳定后，再按同一语言重做九个右键技能。
7. 屏障、治疗、冲刺分别进行独立战术测试，不能只看木桩伤害。

## 10. 验收问题

每个动作完成后必须逐项回答：

- 关掉粒子后，只看师傅本体，还能否辨认这是什么攻击？
- 只看刀光，是否与师傅真实轨迹完全一致？
- 玩家向左上/右上飞行时攻击，纵向动量是否原样保留？
- 敌人是否因为左键被强制移动？答案必须是否。
- 接触效果是否只在真实命中时出现？
- 四段是否能仅凭轮廓和节奏区分？
- 高攻速下启动、有效和收招是否仍按比例稳定？
- 多人模式下动作方向、接触事件和声音是否只发生一次？

只有这些问题通过，额外粒子才有意义。
