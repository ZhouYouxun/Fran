## 格式与缺图处理

将正式的 tModLoader 玩家盔甲帧图放在本目录中，采用以下名称：

| 部位 | 文件 | 当前缺图时的占位 |
| --- | --- | --- |
| 头部 | `Fran_Head.png` | 原版钛金面具 |
| 身体和手臂 | `Fran_Body.png` | 原版钛金胸甲 |
| 腿部 | `Fran_Legs.png` | 原版钛金护腿 |

接入点：`Content/Companions/FranCompanionAppearance.cs`。各部位单独检测；缺少任何一张图都不会阻止召唤。三个名字和帧布局符合时，重新构建并重载模组即可自动替换，无需修改战斗代码。运行中的游戏不会热加载刚复制的文件。

图片必须使用当前 tModLoader 的 Head、Body（复合身体/手臂）、Legs 装备贴图布局，而不是单帧立绘。请保留透明背景、原版玩家尺寸与对应动作帧；身体图须含复合手臂区域。交付时可以参考当前 tModLoader ExampleMod 的三类装备图。若你的素材是自定义尺寸或不同排帧，集中在上述外观文件适配，不要修改 AI。

当前钛金套仅用于绘制，不运行钛金盔甲的属性或套装奖励；翅膀暂用天使之翼。不会覆盖真实玩家的装备或外观，也不会替换游戏全局的钛金贴图。
